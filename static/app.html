How we verify

    
Renting a stranger's GPU needs trust on both sides. These are the checks that make it safe, and you can inspect every one of them.

    

      
The meter reads the hardware
Every second, the host software asks the graphics card how busy it is, using NVIDIA's own reporting library. A second is paid only if the GPU was at least 20% busy.

      
Your money waits in escrow
Before any work starts, your payment is locked in a smart contract on MST Blockchain. Nobody, including us, can take it early. If a job is never settled, anyone can trigger a full refund after one hour.

      
Cheating costs the host its deposit
Every host locks a security deposit. If the GPU telemetry backs less than half of the work a host claims, the contract gives you your payment back plus that deposit. Slow starts are never punished, because you don't pay for them anyway.

      
Strangers' code stays sealed
Jobs run in a Docker sandbox with no internet, read-only files, a powerless user and memory limits. The only thing shared is the GPU you are paying for.

      
You can check your files yourself
Each file carries a SHA-256 fingerprint taken on the host. It is checked again when it reaches you, and you can re-test the trained model on your own laptop.

      
Prices are locked when you book
The price rises when demand is high, like a surge, but a job always pays the price shown when it was booked.
